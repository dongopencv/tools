- **根因3 唯一报错插件**：`dsh-auto-handoff` 写成 `link:D:/PC0/plugins/dsh-auto-handoff`，该目录 0 文件、无 package.json → 插件页「异常/包不可用」，也是 `.plugin-manager` 里 `pnpm install exit 1` 的来源
- 处置：合并 workspace.json（显式 UTF-8 读写）→ `Disable-ScheduledTask DSH-Web` → `DSH-Tunnel` 改指 3081 → 删 auto-handoff 依赖与 junction（deps 19→18、bundles 24→23）→ 删 `DSH-PluginRestore`
- 访问：局域网 `http://192.168.1.37:3081/` PIN **83255858**；公网 quick tunnel PIN **86500397**（首屏 25-40s）
- 市场**不需要额外代理**：dshopen 1.6MB / awesome 3.6MB / GitHub / npmmirror 全直连 200
- **踩坑（务必记住）**：给 PC0 写 `.ps1` 绝不能带中文且无 BOM——PS5.1 按 GBK 解码 UTF-8，中文字节会吃掉后面的引号括号，报 `TerminatorExpectedAtEndOfString`，整脚本不执行。要么纯 ASCII，要么带 BOM
- **踩坑**：该 profile 是 `nodeLinker: hoisted`，`.pnpm` 里只有 `lock.yaml` 属正常，不能用它判断 node_modules 完好
